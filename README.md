# 🎬 NLP Text Classification - Movie Sentiment Analyzer

## 📌 Overview
This project implements NLP preprocessing techniques and builds a machine learning model to classify movie reviews as **positive** or **negative**.

## ✅ Assignment Requirements Covered

| Technique | Implementation |
|-----------|----------------|
| Tokenization | NLTK word_tokenize |
| Stopword Removal | NLTK stopwords |
| Lemmatization | WordNetLemmatizer |
| CountVectorizer | Bag-of-words with n-grams |
| TF-IDF | Term frequency-inverse document frequency |
| ML Models | Naive Bayes, Logistic Regression, SVM |
| Evaluation | Accuracy, Precision, Recall, F1-Score |

## 🏆 Best Model Performance
- **Configuration:** TF-IDF + Logistic Regression
- **Accuracy:** 85%+
- **Precision:** 85%+
- **Recall:** 85%+
- **F1-Score:** 85%+
